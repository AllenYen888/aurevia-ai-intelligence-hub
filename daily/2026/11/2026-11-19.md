# Copilot 新增八種 MCP 連接器：美容預約與品牌工作流

## 摘要
GitHub 於 2026-11-18 宣布八款 GitHub-verified MCP 連接器公開預覽：Box、Buildkite、Calendly、ClickUp、Mixpanel、Supabase、Webflow、Wix。可在 Copilot 中授權連接第三方服務；功能以服務權限及產品實際支援為準，不等於全自動執行所有業務。

## 操作步驟
1. 開啟 GitHub Copilot app，進入 Customize，找到所需服務並選 Connect；或在 Copilot CLI 執行 `/mcp` 並切換 Connectors。
2. 依第三方服務登入授權，先檢查存取範圍。
3. 使用非機密測試資料查詢預約或專案狀態，逐項人工核對，不直接執行對客戶有影響的操作。

## 提示詞範例
「請使用已授權的 Calendly 連接器，列出測試行事曆本週的預約類型與可用資訊；不要新增、修改或取消預約。列出你使用的資料來源與不確定處。」

## 費用、限制與查證
- GitHub 官方稱連接器公開預覽適用所有 Copilot 方案；不代表 Copilot 或第三方服務全部免費。
- Copilot Business/Enterprise 管理員須啟用 Editor preview features；企業 MCP allowlist 可能還須加入連接器；部分服務端也需管理員啟用。
- 未登入實測、未驗證第三方實際操作及額外收費。不得將 AI 輸出視為已完成預約或網站更新。
