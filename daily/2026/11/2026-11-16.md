# GitHub Copilot 六款模型12月14日退場：先盤點AI工作流

## 摘要
GitHub於2026-11-13公告，2026-12-14起將停止提供 Claude Fable 5、Claude Haiku 4.5（個人年度訂閱有例外）、Gemini 3.8 Flash、Gemini 4 Argon、Grok 4.6、Kimi K3。適用 GitHub Copilot 各種體驗；不是指這些模型在所有其他平台停止供應。

## 建議替代
- Claude Fable 5 → Claude Fable 5.2
- Claude Haiku 4.5 → Claude Haiku 5.5（個人年度訂閱有例外）
- Gemini 3.8 Flash → Gemini 4 Hydrogen
- Gemini 4 Argon → Gemini 4 Carbon
- Grok 4.6 → Grok 4.7
- Kimi K3 → 待公告

## 操作步驟
1. 開啟 GitHub Copilot 模型選單，記錄現用模型與方案。
2. 檢查自動化、IDE、提示詞或團隊政策有無指定舊模型。
3. 依官方建議選擇替代模型，用不含機密資訊的美容預約表單或社群文案管理測試案逐項比較輸出、成本及錯誤率。
4. 若為 Business / Enterprise 且替代模型未出現，請管理員核對 Copilot 模型政策。
5. 記錄測試結果與回退方案，再更新正式工作流程。

## 提示詞範例
```text
你是AI工作流程驗收員。請比較以下兩個Copilot模型在「美容工作室預約表單」測試專案的任務完成率、錯誤、資料安全與用量成本。先列出測試項目與可量測標準；不要假設模型已通過測試，也不要使用真實客戶個資。
```

## 適用場景
中小企業網站開發、品牌行銷自動化、AI課程實作、代理式程式任務。

## 方案／限制
Copilot 模型可用性與用量計費依訂閱方案及管理員政策而異；官方公告未提供可套用所有方案的統一免費額度。Claude Haiku 4.5 個人年度訂閱者有退場例外。Kimi K3 尚無指定替代。此公告不是一般 Gemini／Claude 應用的全面下架。尚未實測。
