# VS Code Agent Inbox：跨工作區優先處理待審查任務

## 來源與摘要
GitHub 於 2026-11-16 公告 VS Code 1.146 的 Copilot Agents 視窗 Sessions 清單加入實驗性 Inbox 模式，跨工作區整理工作階段，優先顯示需要使用者注意的工作，並提供 dismiss、hold、snooze 管理選項。這是工作階段管理，不是 AI 自動審核品質保證。

原始來源：https://github.blog/changelog/2026-11-16-github-copilot-weekly-releases-november-9/

## 三個關鍵重點
1. 跨工作區整理 Agent sessions。
2. 優先顯示需要人工注意的階段。
3. 可暫緩、保留或移除清單項目，仍需人工驗收。

## 操作步驟
1. 確認 VS Code 更新至 1.146 或相容版本，並具 Copilot 使用權限。
2. 開啟 Agents 視窗及 sessions 清單，查看是否提供 Inbox 模式。
3. 以不含客戶個資的測試專案啟動一項 Agent 任務。
4. 檢視待注意工作階段，記錄需人工確認的修改、測試與發布決策。
5. 對每項輸出進行人工驗收，才決定是否採用。

## 提示詞範例
> 請為美容工作室的預約表單列出三個待開發任務、每項驗收條件與可能的個資風險。只提出計畫，不要存取真實客戶資料，也不要部署。

## 費用與權限
此項屬 GitHub Copilot 與 VS Code 整合功能，並非宣稱所有免費 VS Code 使用者都能使用。實際 Copilot 訂閱費用、版本、權限及功能開放情況應依官方帳號頁面確認；本來源未提供可確認的此功能獨立定價。
