# 一人公司也能用 GitHub 管理 AI 專案

## 摘要
GitHub 官方於 2026-11-11 宣布，個人帳號擁有的儲存庫也可使用 Issue types 與 Issue fields。預設類型 Bug、Task、Feature；預設欄位 Priority、Effort、Start date、Target date。可自訂最多 25 種類型及 25 個欄位，欄位支援文字、數字、日期、單選、多選。可搭配 GitHub Projects 及 REST/GraphQL API 管理。

## 三步操作
1. 開啟 GitHub 個人帳號 Settings → Planning → Issue types，設定 Task、Feature、Bug 等類型。
2. 於 Planning → Issue fields，設定優先級、預估工時、開始日、目標日等欄位。
3. 在自己的儲存庫建立 Issue，選擇類型並填入欄位；用 Projects 規劃 AI 貼文、短影音、招生專案。

## 可複製 AI 提示詞範例
「你是美業品牌專案經理。請把『一週製作 3 篇 AI 教學貼文及 2 支短影音』拆成 5 筆 GitHub Issue。每筆輸出標題、類型（Task/Feature/Bug）、優先級、預估工時、目標日期、完成驗收標準。不要編造已完成的工作。」

## 適用情境
個人美容工作室、AI 教學講師、品牌顧問、小型行銷團隊；用 Issue 管理內容製作和交付，不代表 GitHub 自動生成 AI 內容。

## 費用與限制
公告未逐項明示方案費用；不可據此保證所有進階 Projects 功能免費。須有 GitHub 帳號與可管理的儲存庫。實際功能依帳號權限與介面而定。此篇僅核實官方公告，未操作實測。
