# Gemini 4 Hydrogen 登陸 GitHub Copilot

## 摘要
GitHub 於 2026-11-13 公告 Gemini 4 Hydrogen 已正式提供於 GitHub Copilot，著重快速代理式程式任務、工具使用與多步驟工作流程。相較 Gemini 3.8 Flash，官方表示指令遵循有所改進；這是廠商描述，非本次獨立基準測試。

## 三個重點
1. 適合多步驟程式工作與工具操作。
2. 支援 VS Code、Visual Studio、CLI、GitHub 網頁、行動版、JetBrains、Xcode 等介面，依逐步推出情況而定。
3. 支援 Copilot Pro、Pro+、Max、Business、Enterprise，依提供者定價採用量計費，企業管理員可透過模型政策控管。

## 三步操作
1. 進入支援的 GitHub Copilot 介面，確認帳號方案及模型選單。
2. 選擇 Gemini 4 Hydrogen，建立不含客戶個資的測試專案。
3. 提交美容預約表單需求，檢查產出程式的功能、安全、資料保護與部署需求。

## 可複製提示詞
> 請先不要直接部署。為一間美容工作室規劃預約表單的前端原型，包含服務選項、日期時間、聯絡方式、輸入驗證與錯誤提示。先列出需求、資料風險、檔案結構及驗收清單，再逐步實作。僅使用虛構測試資料。

## 適用對象
美業數位轉型顧問、中小企業網站開發者、AI 講師與行銷自動化團隊。

## 費用與限制
不是免費 Gemini 聊天服務；需要符合資格的 Copilot 訂閱，並按官方用量計價。模型逐步開放，企業管理員可能停用。產生的程式仍須人工測試、安全審查與法遵檢查；本次未親自執行模型。
