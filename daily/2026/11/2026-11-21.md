# AI Agent 團隊共用，不必每人重設

## 摘要
GitHub 2026-11-18 宣布 Copilot Team Customizations 正式可用。組織的 Team 維護者及組織擁有者，可為團隊選定 Agent Plugins 作為預設。直接團隊成員可在 VS Code、GitHub Copilot app、Copilot CLI 使用；子團隊不會自動繼承。企業與組織政策優先，個別成員可在政策允許時停用。

## 操作步驟
1. 使用具權限的 GitHub 組織帳號進入 Team 頁面。
2. 點選 **Customize Copilot**，從允許的 marketplace 挑選一項已核准 Agent Plugin。
3. 加入團隊，請一名直接成員在 VS Code 或 Copilot CLI 驗證是否出現，記錄結果。

## 提示詞範例
「請依團隊已核准的工具，整理美容品牌網站更新工作的步驟、需要人工核准的操作及驗收清單；不要接觸真實顧客資料。」

## 適用情境
品牌網站維護、行銷自動化工程、AI 教學團隊共用外掛設定；不是一般非技術人員的免費聊天功能。

## 費用、權限與限制
- 僅 Copilot Business／Copilot Enterprise；需相應付費訂閱，未查得此功能獨立加價。
- 組織與企業政策優先；子團隊不繼承；外掛執行仍須遵守個別權限。
- 未實際登入測試，實際可用性以組織設定及客戶端為準。
- 本期未找到可核實的近72小時 Instagram／Threads 原始教學貼文，改採72小時範圍邊界附近的 GitHub 官方公告（11/18）。

## 1. 在Teams交付一份可核對的課程摘要

- 穩定ID：hermes-teams-cloud-connection
- 工具：Hermes Agent／Nous Portal Teams連接
- 應用分類：文字／文件／團隊Agent
- 解決問題：團隊需在既有Teams對話交付資料摘要，而不想另開一套工作介面。
- 摘要：官方提供Teams連接Nous Portal雲端Agent的步驟。此入口是雲端連接器，與自行部署Teams bot、Foundry預覽方案不同；不假設可讀取整個企業檔案。
- 三步操作：
  1. 請管理員允許Hermes Agent，於Teams Apps加入；先確認Nous帳號已有Agent。
  2. 在Nous Portal的Agent設定開啟Team Gateway，選Link Teams，將當次指令私訊給bot；不要分享連接碼。
  3. 用一份虛構課程說明測試摘要，逐項比對日期、費用與缺漏；群組使用@mention，檔案測試限1對1。
- 適用對象：已使用Teams、有管理員協助的中小企業、課程與品牌團隊
- 應用例：把虛構美容講座說明整理成三點重點與待確認清單；編輯建議，未實測。
- 費用／免費額度：Nous Portal／Enterprise實際費用與免費額度未確認；GitHub核心程式MIT不代表雲端服務免費。
- 限制／隱私：訊息與私訊檔案會經Nous連接器傳至雲端Agent；不用真實顧客健康資料。連接碼10分鐘到期，個人帳號各自連接；目前不支援外部組織訪客。

## 2. 先給AI查詢工具，再決定寫入權限

- 穩定ID：langsmith-tool-gateway-beta
- 工具：LangSmith Tool Gateway
- 應用分類：Agent／MCP／自動化治理
- 解決問題：多個Agent各自保存憑證、可用工具及操作身分不易管理。
- 摘要：官方11/19推出公開Beta，集中管理工具憑證、呼叫身分及政策。工具kit整理可見工具；真正的呼叫限制仍須權限與政策，不能只靠隱藏工具。
- 三步操作：
  1. 確認Plus或Enterprise與所需角色，在Tools新增官方公開文件MCP作測試，不先串客戶系統。
  2. 建立只包含文件搜尋的tool kit，將其MCP URL連到支援的客戶端。
  3. 要求搜尋一個文件主題並核對結果；若要增加寫入，另設政策並確認方案可用性及呼叫身分。
- 適用對象：有工程協助的中小企業、AI顧問與自動化維護者
- 應用例：讓教學Agent只查官方文件，再由人決定是否更新課程筆記；編輯建議，未實測。
- 費用／免費額度：官方限LangSmith Plus／Enterprise；確切新增用量費及免費額度未確認。
- 限制／隱私：Beta；憑證由LangSmith保存。kit只決定工具清單，不代替權限。先用公開文件與測試帳號，避免把真實客戶資料或API密鑰放進公開庫。
