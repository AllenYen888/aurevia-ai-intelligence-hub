## 收錄範圍

X.com、Threads、Instagram 的公開原始實作分享，以及工具官方文件與 GitHub 專案。涵蓋內容、圖像、影片、研究、Agent、程式與商業應用。

## 收錄標準

每篇包含來源網址、查核日期、適用對象、解決問題、三步驟、成本限制及驗證狀態。分清官方確認、作者展示、編輯建議與親自實測。僅摘要與連結，不搬運全文；不存放密碼、API 金鑰或個資。無法查核時明確說明，不能把舊內容稱為今日新聞。

## 檔案規則

文章放 daily/YYYY/MM/YYYY-MM-DD.md；資料放 data/YYYY-MM-DD.json。新增文章並回讀核對後，才更新 INDEX.md。以來源 URL 與工具名稱去重。FB 發布成功後才記錄實際貼文連結。
